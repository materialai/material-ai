# 新材料工艺偏差排查AI系统

> 基于「AI头脑风暴 + 排除法导航」范式的工艺偏差根因排查系统
> 让AI不再"猜测答案"，而是"帮你少走冤枉路"

## 核心理念

| 传统方案 | 本系统 |
|---------|--------|
| AI端到端自动闭环（不切实际） | **AI广度搜索 + 人的深度判断** |
| AI计算概率（幻觉风险高） | **Python贝叶斯引擎算概率，大模型只做文本理解** |
| 追求"一次命中"成功 | **追求"排查轮次从7轮降到3轮"的渐进价值** |
| 依赖全量数据训练 | **知识库持续生长，越用越聪明** |

## 架构

```
┌──────────────────────────────────────────────────────────────┐
│  交互层：研发填报试验结果 / 自然语言描述问题 / 选【确认/排除】    │
├──────────────────────────────────────────────────────────────┤
│  RAG检索层：PGVector 余弦相似度召回 Top4 知识片段              │
├──────────────────────────────────────────────────────────────┤
│  推理层：豆包企业API × 4套提示词（抽取/追问/头脑风暴/方案卡）    │
├──────────────────────────────────────────────────────────────┤
│  知识库：PostgreSQL 5业务表（配方/试验/经验/案例/方案）         │
├──────────────────────────────────────────────────────────────┤
│  数据流：填报→RAG召回→大模型假设→贝叶斯概率排序→追问→确认→方案  │
└──────────────────────────────────────────────────────────────┘
```

## 快速开始

### 1. 环境准备

- Python 3.10+
- PostgreSQL 14+ 并启用 pgvector 扩展
- 豆包企业模型接入点

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 初始化数据库

```bash
# 创建数据库
createdb material_db

# 建表（含pgvector）
psql -U postgres -d material_db -f data/db_init.sql
```

### 4. 配置

```bash
cp .env.example .env
# 填入真实的 DOUBAO_API_KEY 和 PG_PASS
```

### 5. 灌入种子知识

```bash
python init_knowledge.py
```

### 6. 端到端测试

```bash
python diagnosis_engine.py
```

### 7. 运行单元测试

```bash
python -m pytest tests/ -v
```

## 工作流程

### 场景A：试验发现偏差

```
研发人员输入：
"高分子聚合反应，收率低于预期30%，原料外观颜色偏深有结块，"
"存放超过一个月，当前是梅雨季节"

系统自动：
1. PGVector召回原料吸湿经验（相似度0.15）、梅雨案例（相似度0.18）
2. 豆包API生成5条假设（仅文本，无概率）
3. 贝叶斯引擎计算概率：
   - 原料吸湿降解 ............ 52%
   - 梅雨季湿度影响反应 ...... 18%
   - 催化剂活性失活 .......... 15%
   - 温度控制参数漂移 ......... 10%
   - 【未验证】搅拌桨磨损 ....... 5%
4. 输出首轮3道追问（单选）
5. 用户逐一选择答案
6. 后端更新概率 / 排除已否定假设
7. 最多3轮锁定根因 → 生成改善方案卡片
```

### 场景B：录入一点课经验

```
张工输入：
"供应商甲的原料在梅雨季节生产的那批，做出来的产物颜色发黄，"
"可能是原料吸水了含水量偏高"

系统自动：
1. 抽取结构化：trigger_condition + exp_content
2. 入库经验规则表（初始置信度 0.5）
3. 向量化写入知识库
4. 后续排查命中此规则时 → 置信度+0.05
   后续排查排除此规则时 → 置信度-0.10
```

## 风控设计

| 规则 | 实现方式 |
|------|---------|
| AI不能算概率 | 假设文本回传后端，贝叶斯纯Python计算 |
| 未验证猜想不参与加权 | 无知识库来源的假设固定权重0.2 |
| 熔断兜底 | 3轮追问无结论自动转专家 |
| 人工审核闸门 | AI输出不直接入库，研发确认后生效 |
| 幻觉拦截 | 入库前数值范围校验（温度/收率阈值） |
| 置信度审计 | confidence_history 表记录每次变更原因 |
